# Content checks

Existing house rules: American English and sentence case. Use specific action verbs, accessible image alternatives, and the glossary in rules.json. Proper product and technology names retain their spelling.

`node check-copy.js` checks component string defaults, literal UI labels and design-system guidance. It does not lint code examples, URLs, translation keys or caller data. Sentence-case and action-verb findings require editorial review; localization and context can make a literal intentional. Missing image alternatives and dictionary matches are actionable findings.

The initial existing-copy baseline is explicit in baseline.json. It preserves old copy without widening this task to every component. New findings fail check-system. Removing old findings is allowed. A baseline is never regenerated by a build; review each update with the owner. `node check-copy.js --strict` also reports existing findings.
