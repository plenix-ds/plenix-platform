# Plenix — Brand Identity Specification

## Brand essentials
- **Name:** Plenix
- **Tagline:** Where All Data Connects
- **Primary color:** `#2A6FDB` (RGB 42, 111, 219)
- **Wordmark color:** `#171B22`
- **Supporting text:** `#586476`
- **Typeface:** Inter; wordmark SemiBold 600; tagline Medium 500.
- **Mark:** Four 90-degree corner brackets, assembled from four identical square L geometries, 90-degree rotational symmetry. All edges square, no rounded corners. Central white cross-shaped opening.

## Design geometry
- Original symbol is constructed in a `100 × 100` coordinate grid.
- Top-left module path: `M0 0 H46 V24 H24 V46 H0 Z`.
- Other three modules are rotated around the center.
- 8 unit central channel separates top from bottom and left from right.
- Never change individual module proportions or spacing.

## Approved applications
- Blue mark on white.
- Black mark on white.
- White mark on blue or dark background.
- Standalone symbol, horizontal lockup, and stacked lockup.
- Keep enough surrounding clear space, at least 10% of icon width on all sides.
- Test at 16 px, 32 px, and 64 px; minimum size is use-dependent and not formally validated.

## SVG font note
The logo SVGs retain editable text using `font-family: Inter, Arial, sans-serif`. Install Inter for exact intended typography. Convert type to vector outlines in your preferred design tool before handing off to a vendor if required.
