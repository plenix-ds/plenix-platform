### Changed
- The column-manage dialog and the grid's error state load on first use in the npm package (#807): `engine/chromeRare.jsx`, drawn by `engine/rare.jsx` once its dynamic import has loaded (the same pattern as the lazy cell range, #848). A bundler such as Vite or Rollup puts the dialog (its list, search, reorder and the components only it needs) in its own chunk, so `import { DataGrid }` is about 36 KB smaller at the start (444.0 to 407.9 KB with the dependency fix, measured with Vite; the dialog opens one network load later the first time, from the cache after). In the CDN script and the application bundles (iife, pages opened from `file://`) the import is inlined: nothing is fetched and the dialog opens at once, as before. Nothing else changes for a person; `{ Button }` and `{ Badge }` keep today's size.
