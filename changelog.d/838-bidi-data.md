### Fixed
- A spaced phone number or IBAN keeps its digit groups in order on an Arabic page (#838, Unicode rule N1): "(617) 555-0142" read ٦١٧ ٠١٤٢ ٥٥٥ in `Text variant="data"` (also with an explicit `dir="ltr"`), `PropertyList.Item data` and a DataGrid or Table cell of kind data, because with Arabic-Indic digits and no strong letter the spaces between the groups take the page's direction. A data value with no letter of a right-to-left script is now a left-to-right island, as Isolate already was by default (`Text` data gets `dir="ltr"` and `unicode-bidi: isolate-override`; `Isolate dir="auto"` resolves to it too, through the new `readsLeftToRight()` in `utils/direction.ts`); a value with an Arabic letter in it, or an element as its child, keeps `dir="auto"`. Nothing changes in a left-to-right page. Test: `tests/bidi-data-838.test.js` (written, not run).
