### Added
- An overflow list, `OverflowList` (#811, the last of its four parts): `<OverflowList items={[{ id, label, icon, href, onSelect }]} />` is one row of items that shows the ones that fit and puts the rest behind a "…" button that opens them in a menu, the behavior the Toolbar's More has, for any row. An item is a ghost button by default, or your own element (`content`: a Tag, a link) in the row, and a menu item (with the same `label`, `icon`, `href` and `onSelect(id)`) once it folds. The row never wraps; items fold from the end until the rest and the "…" button fit; the button is the last thing in the row at the end in both directions. It is measured from the items' widths in a copy that is hidden from the page and from assistive technology (`aria-hidden`, `inert`), so it follows the container and window, changed items or labels, and the fonts loading. The button's name is the catalog's `overflowList.more` ("More items", Arabic "عناصر أخرى"); the row is a named group when it has a `label`. New token: `overflow-list-gap` (the toolbar's cluster gap). The design spec's Overflow menu page gets an example at three widths. Test: `tests/overflow-list-811.test.js` (written, not run; it opens a browser).
