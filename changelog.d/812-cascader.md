### Added
- Four Cascader extras (#812): **choose a parent** (`choosableParents`, or `choosable` on one option): "Europe" can be the answer, not only "Paris"; a choosable parent lists "All of Europe" first in its column, an ordinary row (click, Enter, a checkbox with `multiple`), and a search lists the parent too. **"+N" tags** (`maxTags`, default 3 with `multiple`; 0 shows all): the field shows the first tags and one "+N" tag, a Tab stop named "N more" whose tooltip lists the others on hover and focus (TreeSelect's "… and N more"), and pressing it opens the list. **A limit on choices** (`maxChoices`): past it a click or Enter chooses nothing, and the list says "You can choose up to N." (also announced). **Server search** (`loadOptions(text)`, with `searchable`): the search asks the server with Combobox's rules (`loadDelay` pause in typing, `minChars`, a late answer dropped, a loading row, the count announced, a failed load shown and announced); matches are `{ id, label, path }` (the parents' labels, or `{ id, label }`), the typed text marked by the shared highlight, and a chosen result is named in the field. New words in the catalogs (English and Arabic): `allOf`, `more`, `moreLabel`, `limit`, `loading`, `error`; new tokens: `cascader-loading-gap`, `-error-text`, `-limit-text`, `-limit-font-size`, `-limit-padding-block`, `-limit-padding-inline` (existing roles). The design spec's Cascader page gets the four variants and the loading and failed states. The default of `maxTags` changes what a multiple Cascader with more than three choices shows (three tags and "+N"); pass `maxTags={0}` for the old look. Test: `tests/cascader-extras-812.test.js` (written, not run; it opens a browser). Drawing only the visible result rows is #815.
