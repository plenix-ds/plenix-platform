### Changed
- The width a person drags the side panel or the navigation pane to is remembered per monitor (owner, #463 option C, step 3). Each monitor, named by its screen size, keeps its own width, so a laptop and an external monitor no longer share one. A saved width is used only when it still fits the window (never more than 90%), and comes back when it fits again. The single width saved before carries over as the current monitor's. Stored in `plenix.paneWidths`; the old keys are left in place.
