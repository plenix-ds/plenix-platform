## 8. Feature List

Value-added behavior beyond Create, Edit, Delete, and Search.

Source feature area(s): Leads Manager

| ID | Feature | Status | Description |
|---|---|---:|---|
| F01 | **Lead pipeline — CRM-style deal tracking** | 🔵 Planned | Use case: The user manages sales leads, business development conversations, or client acquisition workflows and needs to track where each opportunity stands without using a full CRM system. The Leads Manager provides a Kanban-style pipeline with customizable stages (e.g. New Lead / Qualified / Proposal Sent / Negotiating / Won / Lost). Each lead is a card containing: company or person name, deal value, expected close date, assigned contact (linked to People section), associated project (if the deal leads to a project), notes, and activity log. Cards move between stages by dragging. A won/lost status on a lead updates the pipeline summary metrics. Leads can be created from the Contacts section (convert a contact to a lead) or from an incoming email (one-click create lead from email sender). |
| F02 | **Lead metrics and pipeline value** | 🔵 Planned | The Leads Manager shows summary metrics at the top of the pipeline: total number of open leads, total pipeline value (sum of deal values across all non-closed leads), weighted pipeline value (each lead's value multiplied by a win probability percentage set per stage), leads won this month, and leads lost this month. A conversion funnel visualization shows how many leads are in each stage and the percentage that advance from one stage to the next — useful for identifying where leads are dropping off in the process. |
