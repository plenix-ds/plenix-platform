# Task #170: P-31: The published TypeScript declarations type DataTable columns and Tabs onChange wrongly (Codex)

Tracker: https://github.com/plenix-ds/plenix-platform/issues/170 · Plan of record: https://github.com/plenix-ds/plenix-platform/issues/3

**From RedSave** (report of 19 October 2026, checked on Plenix 0.58.0). Priority: **Medium**. Owner: **Codex**.

### What goes wrong

plenix.d.ts types DataTable's columns as a string union and Tabs as React.HTMLAttributes (onChange a DOM event, not (value) => void); correct code does not compile.

### Suggested fix

columns?: DataTableColumn[] with a DataTableColumn interface; TabsProps with items, value and onChange(value: string).
