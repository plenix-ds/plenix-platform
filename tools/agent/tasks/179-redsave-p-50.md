# Task #179: P-50: MediaViewer needs every item built up front (Codex)

Tracker: https://github.com/plenix-ds/plenix-platform/issues/179 · Plan of record: https://github.com/plenix-ds/plenix-platform/issues/3

**From RedSave** (report of 19 October 2026, checked on Plenix 0.58.0). Priority: **Medium**. Owner: **Codex**.

### What goes wrong

MediaViewer takes the whole items list though it draws one; for 1,500 images an app builds 1,500 objects per step (RedSave: ~180 ms per Next formatting dates).

### Suggested fix

count with getItem(index) (or renderItem) so only the shown item (and the next, for preloading) is built; document that items should be cheap.
