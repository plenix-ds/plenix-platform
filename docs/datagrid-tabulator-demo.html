Tabulator in Plenix

Tabulator 6.3, stock engine, restyled only with Plenix tokens: shaded header in a heavier weight, sort arrow and filter button that appear on hover, right-click menus on the header and on rows. Example asset data.

Hover a header to see its sort arrow and filter button. A filtered column keeps its button, in blue.
Right-click a header for sort, filter, group by, hide and fit. Drag a header to move it; drag its edge to resize.
Right-click a row for row actions; hover a row for its action buttons. Double-click Name or Status to edit.
First column: Row header shades Name, and the checkbox and paperclip columns before it, like the header, and pins them; scroll sideways to see the other columns pass under it.
The paperclip column marks rows with attachments (hover for the count); click its header to sort them first.
Collections (Crosses, Feast banners) expand into their files. Checkboxes select; the header box selects all.
