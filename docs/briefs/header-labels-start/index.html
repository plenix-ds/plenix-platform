Column header labels: all at the start (#326)

You asked why "Quantity on the shelf" is right-aligned: all column header labels should be consistent. Today a number column's label follows its numbers to the right; you see it most when the label wraps.

  • Cause: number columns set their header to align right (the column's headerAlign, and file-size columns on their own).
  • After: every header label starts at the start edge in DataGrid and Table, whatever the column says. The numbers in the cells stay at the end, as you said nothing about them.
  • Test: a header label never takes its column's alignment (DataGrid and Table).
