Types: before and after (PR #291)

Each case is the same correct app code, checked by TypeScript (tsc --strict) against the definitions we publish. The error text is the real tsc output from the old definitions (0.69.5) and from the new ones built by this PR.

1 · DataGrid columns (#170)

Before, a developer who passed a normal list of columns got an error saying columns must be one word such as "data" or "icon". RedSave could not build a grid without a workaround. After, the list is accepted.

Before: error
app.tsx
const columns = [{ title: 'Name', field: 'name' }];
<DataGrid label="Records" data={rows} columns={columns} />

error TS2322: Type '{ title: string; field: string; }[]' is not
assignable to type '"number" | "data" | "icon" | "center" |
"actions" | "wrap" | "deleted" | … 13 more … | undefined'.
After: no error
app.tsx
const columns = [{ title: 'Name', field: 'name' }];
<DataGrid label="Records" data={rows} columns={columns} />

columns?: any[]   (a list of column records)

2 · Tabs onChange (#170)

Before, the editor said onChange receives a browser event, but Tabs actually sends the chosen tab's value, so correct code was rejected and the hint was wrong. After, onChange takes the value, as Tabs works.

Before: error
app.tsx
<Tabs items={items} onChange={(value: string) => setTab(value)} />

error TS2322: Type '(value: string) => void' is not assignable
to type 'FormEventHandler<HTMLElement>'.
  Type 'FormEvent<HTMLElement>' is not assignable to type 'string'.
After: no error
app.tsx
<Tabs items={items} onChange={(value: string) => setTab(value)} />

onChange(value): runs when another tab is selected

3 · Filter panel with useCollectionView (#170)

Before, connecting the Filter panel to our own collection hook failed: the hook and the panel disagreed about what the fields are. After, the panel takes the hook's props directly, which is how our docs say to use it.

Before: error
app.tsx
const view = useCollectionView(fields);
<FilterPanel {...view.filterProps} />

error TS2322: Types of property 'fields' are incompatible.
  Type 'CollectionField[]' is not assignable to type
  '"number" | "date" | "select" | "multi" | undefined'.
After: no error
app.tsx
const view = useCollectionView(fields);
<FilterPanel {...view.filterProps} />

The same holds for SortPanel, GroupPanel and ColumnsMenu.

4 · MediaCard aspect "4/3" (#171)

Before, the card's own default shape, "4/3", was refused because the list of shapes left out the default. After, every documented shape is accepted.

Before: error
app.tsx
<MediaCard src="/a.jpg" aspect="4/3" />

error TS2322: Type '"4/3"' is not assignable to type
'"1/1" | "16/9" | "9/16" | "3/4" | undefined'.
After: no error
app.tsx
<MediaCard src="/a.jpg" aspect="4/3" />

aspect?: "4/3" | "1/1" | "16/9" | "9/16" | "3/4"
