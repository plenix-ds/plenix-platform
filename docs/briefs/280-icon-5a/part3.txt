## The rule: check-system.rules/icon-imports.js (run by check-system.js; alone: node check-system.rules/icon-imports.js)
- Reads components, patterns, hooks, providers and templates, and Icon.jsx's own tables (StatusIcon), with uses.js.
- A finding: an icon name written as text in an icon slot (or a table it reads), a name built at run time without a
  plx-icons comment, or a string in an icon slot that is not a Plenix name.
- Three named exceptions, each with its reason: File's public fileIcon (and its BY_EXT table) returns names; the
  documented defaults of Thumbnail ('document') and PermissionSummary ('lock').
- Proven: ICON_IMPORTS_OK here; it fails on a name put back in SidePanel (icon="panel-right-close"), on StatusIcon's table
  ('circle-info'), and on an unknown default ('lock-open').
