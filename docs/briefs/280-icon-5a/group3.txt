- Thumbnail: the documented default stays the name (icon = 'document'): the spec shows each prop's default from the
  signature, so converting it changed the spec's prop table ("— DocumentIcon"). The component draws the name's module
  (const glyph = icon === 'document' ? DocumentIcon : icon). convert.js now leaves a parameter's default for a hand fix
  (one left: PermissionSummary's 'lock', in a later group).
- AppHeader: the density menu's icon was built from text ('density-' + value); it is now DENSITY_ICONS[value], with the
  name as the fallback for a workspace's own density (listed in a plx-icons comment).
- File (QA on #532): fileIconModule draws the document icon, and development warns once, when a type's icon has no import.
- RichTextEditor: the plx-icons comment is gone; the scan treats a tuple's numbered field (m[3]) like an item's field.
