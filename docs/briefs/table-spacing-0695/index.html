Table spacing: release 0.69.5 next to the fix

The fix is PR #331 ("each cell gets its top spacing once"), merged on 2026-10-25. No other fix was made for this. The pictures come from 0.69.5 and from styling/phase-2 today (8252f0f9), using the same tables #331's own page used.

In short

  • In 0.69.5, a row of a static Table with wrapped text started its cells at different heights: the label in the middle, plain text a line lower than the code beside it.
  • With the fix, every cell in such a row starts on the same top line, as you approved ("wrapped rows start at the top", wrap spacing option A).
  • Measured (distance of each cell's first line from the row top, State / Looks / Set by / Changes):
    • 0.69.5: 27 / 18 / 18 / 10px (Focus row), 27 / 18 / 26 / 10px (Hover row).
    • The fix: 10 / 10 / 10 / 10px in both rows.
  • The DataGrid with tall wrapped rows already started every cell at the top in 0.69.5 (10 / 10 / 10 / 10px), and still does.
  • Compact and Standard look the same here: wrapped rows grow with their text, and the DataGrid's height is its own row-height setting (Tall), so display density does not change these tables.
  • Other approved changes you will see in the "after" pictures: the shorter header row (#310, the Table header at the DataGrid's Compact height).
