Icons today: what we measured

PR #292 (issue #278) · the first step of the icon plan (#277)

How an icon gets to the screen today

1. The page loads the style file

The pictures of all 178 Plenix icons ride inside it, whether the page needs them or not.

2. An app asks for an icon by name

For example "folder". Plenix looks the name up in its list.

3. Plenix copies the picture out of the style file

Other Material icons (about 4,150 more) are downloaded one by one, only when asked for.

4. The icon is drawn

In the text color, at the size the place calls for.

The numbers that matter

25%

of the style file's download is icon pictures (64 KB of 252 KB)

66 of 178

icons are used by the 11 apps; every page still downloads all 178

13 ms

extra wait the first time a page draws an icon, to copy the pictures out of the style file

6 paths

different ways an icon can reach the screen today; the plan brings them down to one

What this PR changes

Nothing you can see. It adds only a written report and the script that took the measurements. No screen, color or icon changes.

What comes next

  1. #279: decide where the icon pictures live as files and how they are named.
  2. #280: take the Plenix icon pictures out of the style file.
  3. #281: one way to look up every icon, Plenix or Material.
  4. #282: let apps include only the icons they use.
  5. #283: download each icon once and keep it.
  6. #284: make the offline and browser-extension copies carry every icon.
  7. #285: treat downloaded icon files safely.
  8. #286: compare before and after: size, speed and look (no visible change).
